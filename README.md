# Desafio Criativo — Insights de Feedbacks de Clientes Bancários

## Prompt Final

Atue como analista de dados e experiência do cliente de uma instituição bancária.

Sua tarefa é analisar feedbacks de clientes sobre o aplicativo e os serviços digitais do banco, incluindo Pix, pagamentos, cartões e atendimento digital, para identificar os principais problemas, elogios, padrões e oportunidades de melhoria.

### Contexto

A análise será utilizada pela equipe de experiência do cliente para identificar os pontos que mais afetam a satisfação dos clientes e apoiar a definição de melhorias nos serviços digitais.

### Dados disponíveis

Serão fornecidos dados contendo a data do feedback, canal utilizado, produto ou serviço citado, texto do comentário e nota de satisfação de 1 a 5.

### Instruções de análise

1. Classifique os feedbacks por tema, sentimento, urgência e produto ou serviço relacionado.
2. Identifique os principais problemas, elogios e padrões encontrados.
3. Apresente evidências baseadas nos comentários fornecidos.
4. Identifique oportunidades de melhoria.
5. Sugira ações práticas para a equipe de experiência do cliente.
6. Destaque quais problemas devem ser tratados primeiro e explique o motivo com base nos dados.

### Formato da resposta

Apresente um resumo executivo com os principais insights, seguido de uma tabela contendo tema, sentimento, evidência, nível de urgência e ação sugerida.

Ao final, apresente as 3 principais prioridades de melhoria.

### Restrições

* Utilize somente os dados fornecidos.
* Não invente números, causas ou conclusões.
* Não exponha dados pessoais ou sensíveis dos clientes.
* Não faça suposições que não possam ser sustentadas pelos dados.
* Informe claramente quando os dados forem insuficientes para chegar a uma conclusão.
* Utilize linguagem simples, objetiva e adequada para tomada de decisão.
